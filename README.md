# 🔤 NATO Alphabet Converter

> Ever struggled to spell something clearly over a call?  
> This project solves that using the **NATO Phonetic Alphabet**.

---

## 🎯 About

This project converts normal text into the **NATO phonetic alphabet** — a system where each letter is replaced with a specific word (like *A → Alfa, B → Bravo*).

It’s widely used in aviation, military, and communication systems to avoid misunderstandings caused by accents, noise, or poor connections :contentReference[oaicite:0]{index=0}.

## 📚 NATO Alphabet

Here’s the full alphabet used in this project:

```
A - Alfa     B - Bravo    C - Charlie   D - Delta
E - Echo     F - Foxtrot  G - Golf      H - Hotel
I - India    J - Juliett  K - Kilo      L - Lima
M - Mike     N - November O - Oscar     P - Papa
Q - Quebec   R - Romeo    S - Sierra    T - Tango
U - Uniform  V - Victor   W - Whiskey   X - X-ray
Y - Yankee   Z - Zulu
```

👉 Each word is carefully chosen so it sounds distinct and reduces confusion during communication :contentReference[oaicite:1]{index=1}.
